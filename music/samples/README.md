# Instrument samples

Single-note MP3 recordings used by `../opening-theme-sampled.js`. Only the
notes the waltz actually plays are kept, one file per note, named like
`C4.mp3` (flats spelled `Ab`, `Bb`, ...).

- `accordion/` General MIDI 22, Accordion
- `acoustic_bass/` General MIDI 33, Acoustic Bass (plucked upright)
- `marimba/` General MIDI 13, Marimba (stands in for the glockenspiel)

They come from the FluidR3 General MIDI SoundFont as converted to MP3 by the
`soundfont-for-samplers` npm package (v0.0.3). The license below applies to
these files.
